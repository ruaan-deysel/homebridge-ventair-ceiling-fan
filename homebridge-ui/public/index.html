Scan the network

Scans for Tuya devices on the same network as Homebridge. Takes about 30 seconds. A fan already in your config is never removed just because a scan misses it.

Tuya cloud credentials

Used to fetch local keys from your Tuya IoT project. Tuya time-limits access to device data through the IoT portal, so cloud fetch can stop working over time — every fan below also supports pasting its local key in directly, which always works. These credentials are used for the request only and are never saved to your Homebridge config.
